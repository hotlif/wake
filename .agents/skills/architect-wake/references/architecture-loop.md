# L2 架构循环

编辑前发布：

```markdown
架构简报 vN
产品目标与成功条件：
当前架构与证据：
目标架构与所有权：
事实 / 推断 / 决策：
假设 / 实验 / 预期观察：
职责、数据流与不变量：
公共接口、产物与迁移：
删除 / 替换计划：
验证矩阵与收敛条件：
```

证据与简报矛盾时，保留可复现证据并找到第一个失效假设；判断所有权、模型、数据流或实现何处错误，先修订简报和目标模型，再扩大代码变更。删除失效实验和临时路径，并重新运行先前证据。

长期决策使用 `engineering/decisions/0000-template.md`。新 ADR 列出被替代的 ADR；旧 ADR 标记 `superseded` 并指向新 ADR。记录删除项、剩余事实来源、新抽象的使用方，以及所有桥接的负责人、范围、移除条件和最晚里程碑。
