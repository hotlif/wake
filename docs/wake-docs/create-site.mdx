## 创建三个入口

文档可以放在应用仓库中，也可以独立成项目。在项目根创建配置：

```toml title="wake.config.toml"
[docs]
source_dir = "docs"
title = "My Docs"
description = "组件和项目使用指南"
locale = "zh-CN"
```

```toml title="docs/navigation.toml"
[[group]]
id = "start"
title = "开始"
pages = ["index"]
```

## 运行并验证

```bash
npx wake docs dev .
```

打开终端显示的 URL，检查站点名、首页、导航和主题。修改首页描述后保存，重建成功时应刷新。然后停止开发服务并执行：

```bash
npx wake docs build . --outdir docs-dist
```

用 HTTP 静态服务器提供 `docs-dist`，验证首页和资源请求。`kind` 用于描述页面类型。上面的页面可以直接运行；本文档站中的卡片等装饰组件不是创建站点的必需依赖。

## 常见错误

- 未列入导航的页面：加入清单，或对确实不应出现在导航中的页面声明 `hidden = true`。
- 把源码目录作为输出：输出必须独立，不覆盖 docs 或项目根。
- 路径不匹配：确认有效项目根、`source_dir` 和文件名大小写。
