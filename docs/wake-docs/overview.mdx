## 从内容到站点

页面文件决定 URL，导航清单决定阅读顺序。MDX 描述说明文字，Demo 展示真实交互，API 表从源码提取属性。开发时运行本地服务器；发布时输出静态页面和资源，不需要线上运行文档后端。

## 三种定制需求

| 想修改什么 | 使用哪项配置 | 继续阅读 |
| --- | --- | --- |
| 颜色、字体和排版 | `theme_css` | [调整主题](/wake-docs/theming) |
| 顶栏、导航、搜索或内容卡片 | `ui` | [替换第一个组件](/wake-docs/ui)、[Crab UI](/wake-docs/crab-ui) |
| Demo 内的主题、Provider 和基础样式 | `preview` | [配置 Preview](/wake-docs/preview) |

三项配置可以组合使用。属性表从[公开类型](/wake-docs/props-api)生成，页面写法见[MDX](/wake-docs/mdx)。

内容和组件都是可信项目源码。应在仓库中审核后构建，不把 MDX 编译当作处理不可信用户内容的安全沙箱。
