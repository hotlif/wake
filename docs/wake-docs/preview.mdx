# Preview 环境

## 创建包装器

```tsx title="docs/preview.tsx"
import type { ReactNode } from "react";
import "./preview.css";

export default function Preview({ children }: { children: ReactNode }) {
  return <div className="preview-root">{children}</div>;
}
```

```toml title="wake.config.toml"
[docs]
preview = "docs/preview.tsx"
```

Preview 适合注入路由、主题、国际化和数据客户端。它不应替 Demo 隐藏真实依赖，也不应启动共享的不可清理副作用。

未配置 `preview` 时，Wake 会在普通文档站和组件工作台中默认将 Demo 水平、垂直居中；超出视口的内容仍从可滚动的起始边显示。配置自定义 Preview 后，包装器将完全接管布局，Wake 不再叠加默认居中样式。

## 隔离原则

Demo 默认在 iframe 中运行，错误、样式和尺寸不会污染文档外壳。Preview 本身也进入每个 iframe，因此应保持轻量和确定性。

## 验证方式

打开两个不同 Demo，确认状态互不共享；切换文档主题时两个 iframe 都能收到主题更新。
