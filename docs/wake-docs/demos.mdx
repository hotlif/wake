## 创建一个示例

```tsx title="docs/examples/counter.demo.tsx"
import { useState } from "react";

export const meta = {
  title: "计数器",
  description: "验证本地状态与交互",
  viewport: "responsive",
};

export default function CounterDemo() {
  const [count, setCount] = useState(0);
  return <button onClick={() => setCount(count + 1)}>
    已点击 {count} 次
  </button>;
}
```

在 MDX 页面引用它：

```mdx
<Demo src="./examples/counter.demo.tsx" />
```

## 验证方式

点击按钮后数字应增加；切换源码与视口不会丢失整个文档页面。运行时错误只显示在当前 Demo。

多个示例可使用 `<Demos glob="./examples/*.demo.tsx" columns={2} />`；glob 和列数必须是静态值。

## 常见错误

- Demo 不应依赖外部网络、当前时间或页面外的可变全局状态。
- `src` 和 `glob` 必须是静态字面量，构建器才能建立依赖。
