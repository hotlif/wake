## 推荐顺序

每增加一项能力，都保留一个可重复验证的例子。先让本地流程可运行，再把相同命令放进 CI；遇到错误时，从[症状排查](/reference/troubleshooting)定位，再查询对应参考。完整配置不是入门前提。
