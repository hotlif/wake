## 添加最小配置

```toml title="wake.config.toml"
[html]
entry = "src/main.tsx"

[react]
enabled = true
jsx_import_source = "react"
```

入口不同时使用真实路径。先不要复制旧 bundler 的全部选项。

## 验证方式

关键路由、请求和交互结果一致，Wake 产物位于独立目录后，再替换 npm scripts。

## 常见错误

- 浏览器入口依赖 Node 内置模块：换成 Web API 或服务端接口。
- 旧环境变量由插件注入：迁移到 Wake `define`。
- 别名只写在 tsconfig：Wake 仍需要自己的 alias 配置。
