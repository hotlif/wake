## 准备项目

按[安装 Wake](/start/install)准备依赖。以下命令和路径都相对于项目根；不依赖脚手架生成器。

## 创建三个文件

```toml title="wake.config.toml"
[html]
entry = "src/entry.tsx"

[react]
enabled = true
jsx_import_source = "react"
```

```tsx title="src/entry.tsx"
import { useState } from "react";
import { createRoot } from "react-dom/client";
import "./style.css";

function App() {
  const [count, setCount] = useState(0);
  return <main>
    <h1>我的第一个 Wake 应用</h1>
    <button onClick={() => setCount(value => value + 1)}>点击次数：{count}</button>
  </main>;
}

const container = document.getElementById("root");
if (!container) throw new Error("缺少 #root 容器");
createRoot(container).render(<App />);
```

```css title="src/style.css"
:root { font-family: system-ui, sans-serif; color: #18181b; background: #fafafa; }
body { margin: 0; padding: 2rem; }
button { font: inherit; padding: .6rem 1rem; cursor: pointer; }
button:focus-visible { outline: 3px solid #7c3aed; outline-offset: 3px; }
```

未指定 HTML 模板时，Wake 生成包含 `id="root"` 的默认页面。入口负责挂载 React，CSS 通过导入进入构建。

## 添加类型检查

```json title="tsconfig.json"
{
  "compilerOptions": {
    "target": "ES2022",
    "lib": ["ES2022", "DOM", "DOM.Iterable"],
    "module": "ESNext",
    "moduleResolution": "Bundler",
    "jsx": "react-jsx",
    "strict": true,
    "noEmit": true,
    "skipLibCheck": true
  },
  "include": ["src"]
}
```

先为 CSS 副作用导入添加类型声明，使严格检查认识这类资源模块：

```ts title="src/assets.d.ts"
declare module "*.css" {}
```

将以下条目合并进 `package.json` 的 `scripts`，保留安装生成的依赖声明：

```json title="package.json 中的 scripts"
{
  "dev": "wake dev .",
  "typecheck": "tsc --noEmit",
  "build": "wake build --outdir dist"
}
```

## 运行并验证

```bash
npm run typecheck
npm run dev
```

打开终端给出的 URL。连续点击按钮，次数应该增加。把标题文字改掉并保存：重建成功后浏览器整页刷新，标题改变，计数恢复为 0。这是 Live Reload 的预期行为。

另开终端执行 `npm run build`，应得到包含 HTML、JavaScript 和 CSS 的 `dist`。不要直接双击 HTML 判断部署效果；用静态服务器检查，具体步骤见[生产构建](/app/production-build)。

## 常见错误

- 找不到入口：核对配置与 `src/entry.tsx` 的文件名，包括大小写。
- 页面空白：查看终端诊断及浏览器控制台；使用自定义 HTML 时确认有 `#root`。
- 构建成功但类型错误：构建不替代 `npm run typecheck`，两个命令都应通过。
- 保存后计数归零：整页刷新会重新创建 React 状态，不能以此判断 Hooks 失效。
