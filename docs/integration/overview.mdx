## 先验证结果，再扩展流程

使用返回的结构化结果和诊断，不解析终端文字。每一步明确输入、输出和结束条件。构建后检查产物，启动服务后验证所需路由，关闭时等待资源释放。

普通构建 API 与实验接口有不同稳定性。不要因为它们来自同一个 npm 包，就把实验性的编译器原语或测试接口提升为稳定承诺。
