## 第一次使用，走这三步

<StepFlow>
  <Step number="01" title="安装工具">准备 Node.js，在项目里安装 Wake 和所需依赖。</Step>
  <Step number="02" title="运行示例">打开本地页面，点击按钮，修改一行文字。</Step>
  <Step number="03" title="构建发布">生成 dist，用 HTTP 服务检查页面与资源。</Step>
</StepFlow>

按[安装](/start/install) → [创建 React 应用](/start/create-react-app) → [生产构建](/app/production-build)阅读即可。已有源码时，从[接入现有项目](/start/existing-project)开始。

## 用到时再查

想发布可安装的组件包，阅读[库构建](/app/library)；需要组合自动化步骤，使用[Node.js API](/integration/overview)。参数、默认值和错误码集中在左侧“参考与排错”，不必在入门前全部读完。

<Callout title="使用前了解当前范围">
  Wake 当前处于 Beta。样式提取、Wake Test、库构建和低层 API 各有实验性范围；页面会标明状态。运行环境和主要限制见[支持范围](/start/support)。
</Callout>
