# 配置参考

Wake 使用声明式 `wake.config.toml`。配置只描述数据，不执行 JavaScript，因此团队、CI 和不同操作系统能得到一致结果。

## 配置文件放在哪里

Wake 从命令提供的路径开始向上寻找：

1. `wake.config.toml`；
2. 或 `package.json` 所在目录。

找到后，该目录成为配置基准。`root_dir` 可以再改变实际项目根。

如果 TOML 解析失败，CLI 会打印 warning 并回退默认配置。不要忽略 warning，否则可能误以为自定义入口、别名或端口已经生效。

## 从最小配置开始

```toml title="wake.config.toml"
[html]
entry = "src/entry.tsx"

[react]
enabled = true
jsx_import_source = "react"
```

只有确实需要时再加入代理、扫描和 transforms。

## 完整示例

```toml title="wake.config.toml"
root_dir = "."
public_path = "/"
browserslist = [
  "chrome >= 120",
  "firefox >= 121",
  "safari >= 17.2",
]

[alias]
"@shared" = "src/shared"
"@assets" = "src/assets"

[define]
"__APP_VERSION__" = "\"0.1.0\""
"process.env.API_URL" = "\"https://api.example.com\""

[html]
template = "public/index.html"
entry = "src/entry.tsx"

[typescript]
enabled = true
only_remove_type_imports = true

[react]
enabled = true
jsx_import_source = "react"

[browserslist_options]
mobile_to_desktop = false

[transforms]
include = []
exclude = []

[dev_server]
server = "http"
host = "127.0.0.1"
port = 5173
open = false

[[dev_server.proxy]]
context = ["/api"]
target = "http://127.0.0.1:8080"
change_origin = true
ws = false

[dev_server.proxy.path_rewrite]
"^/api" = ""

[[component_scan]]
namespace = "ui"
cwd = "src/components"
include = "\\.(tsx|ts)$"
exclude = "\\.(test|spec)\\."
generate_source = false

[docs]
source_dir = "docs"
title = "组件库"
description = "设计系统与组件使用指南"
locale = "zh-CN"
logo = "/logo.svg"
repository_url = "https://github.com/example/ui"
base_path = "/"
preview = "docs/preview.tsx"
theme_css = "docs/theme.css"
default_theme = "system"
accent_color = "#7c3aed"
```

## 根级字段

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `root_dir` | 字符串或省略 | 配置目录 | 后续相对路径的项目根 |
| `public_path` | 字符串或省略 | `/` | 普通应用资源与异步 chunk 前缀 |
| `browserslist` | 字符串数组 | 现代固定基线 | 浏览器转换目标 |
| `alias` | 表 | 空 | 自定义解析别名 |
| `define` | 表 | 空 | 编译期源码替换 |
| `component_scan` | 表数组 | 空 | 自动生成组件注册模块 |
| `transforms` | 表 | 空 | 强制启用或排除转换 |
| `docs` | 表 | 默认 Docs 配置 | 组件文档站 |
| `dev_server` | 表 | 默认值 | 开发服务和代理 |

### root_dir

```toml
root_dir = "packages/web"
```

它相对配置文件目录解析。设置后，`@`、`@@`、入口、扫描目录和 `.wake` 都以新根为基准。路径不存在时 CLI 会警告并回退配置目录。

### public_path

部署到网站子路径：

```toml
public_path = "/console/"
```

通过 Electron 的 `file://` 或其他本地文件方式加载普通应用：

```toml
public_path = "./"
```

相对模式会让入口脚本、CSS、异步 chunk 和独立资源使用 `./` 前缀。

`public_path` 只用于普通应用。文档站使用 `[docs].base_path`，不要混用。

## 浏览器目标

显式配置优先：

```toml
browserslist = [
  "chrome >= 120",
  "edge >= 120",
  "firefox >= 121",
  "safari >= 17.2",
  "ios_saf >= 17.2",
]
```

查找顺序：

1. `wake.config.toml#browserslist`；
2. `.browserslistrc`；
3. `package.json#browserslist`；
4. Wake 固定现代基线。

默认基线是 Chrome 120、Edge 120、Firefox 121、Safari 17.2 和 iOS Safari 17.2。

```toml
[browserslist_options]
mobile_to_desktop = false
```

`mobile_to_desktop` 控制移动浏览器缺少版本数据时是否回退对应桌面数据。

## TypeScript

```toml
[typescript]
enabled = true
only_remove_type_imports = true
```

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 对 `.ts`、`.tsx` 执行 TypeScript 语法擦除 |
| `only_remove_type_imports` | `true` | 保留值导入，只移除类型导入语义 |

Wake 负责编译，不等同于完整 TypeScript 类型检查。项目仍建议在 CI 单独运行 `tsc --noEmit`。

## React

```toml
[react]
enabled = true
jsx_import_source = "react"
```

`enabled` 开启 JSX 转换，`jsx_import_source` 指定 automatic runtime 来源。React 项目通常保持默认。

Wake Docs 最低要求 React 19，并检查当前项目根的 `react` 与 `react-dom` 版本声明。

## Define

值是替换后的 JavaScript 源码，不是普通 TOML 文本：

```toml
[define]
"process.env.API_URL" = "\"https://api.example.com\""
"__FEATURE_SEARCH__" = "true"
"__MAX_ITEMS__" = "100"
```

字符串需要包含转义引号；布尔和数字写合法 JavaScript 字面量。

Wake 根据命令注入：

```text
wake dev / wake docs dev       process.env.NODE_ENV = "development"
wake build / wake docs build   process.env.NODE_ENV = "production"
```

用户声明的同名 define 最终覆盖默认值。不要把 API 密钥写进 define，替换结果会进入浏览器产物。

## HTML

```toml
[html]
template = "public/index.html"
entry = "src/entry.tsx"
```

入口优先级是 CLI `ENTRY` 或 `--entry`、配置 entry、`src/entry.tsx`。

模板优先级：

1. `[html].template`；
2. `public/index.html`；
3. Wake 内置 HTML 外壳。

自定义模板至少要保留应用挂载所需节点。普通应用当前不会因为使用 public 模板就自动复制整个 public 目录。

## 别名

```toml
[alias]
"@shared" = "src/shared"
```

Wake 还提供：

- `@` → `<root>/src`；
- `@@` → 项目根；
- `@@@/<namespace>` → 扫描生成模块。

别名按前缀解析，名称应避免彼此含义重叠。团队项目建议统一一套命名规则。

## 开发服务器

```toml
[dev_server]
server = "http"
host = "127.0.0.1"
port = 5173
open = false
```

`wake docs dev` 的端口优先级是 CLI、配置、5173。普通 `wake dev` 当前 CLI 自带 5173 默认值，需要其他端口时显式传入。

代理规则详见“开发与 HMR”。`proxy` 是数组，因此每条规则使用双中括号 `[[dev_server.proxy]]`。

## 组件扫描

```toml
[[component_scan]]
namespace = "ui"
cwd = "src/components"
include = "\\.(tsx|ts)$"
exclude = "\\.(test|spec)\\."
generate_source = false
```

`include` 和 `exclude` 是正则字符串。在 TOML 双引号中，反斜杠需要转义，所以正则 `\.` 写成 `\\.`。

多组扫描可以重复声明：

```toml
[[component_scan]]
namespace = "icons"
cwd = "src/icons"
include = "\\.tsx$"
```

## 文档配置

```toml
[docs]
source_dir = "docs"
title = "Crab UI"
description = "React 19 组件使用指南"
locale = "zh-CN"
logo = "/logo.svg"
repository_url = "https://github.com/example/ui"
base_path = "/"
preview = "docs/preview.tsx"
theme_css = "docs/theme.css"
default_theme = "system"
accent_color = "#7c3aed"
```

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `source_dir` | `docs` | 递归扫描 MDX 的目录 |
| `title` | `Wake Docs` | 顶栏和 HTML 站点标题 |
| `description` | 空 | 站点描述回退 |
| `locale` | `zh-CN` | `zh-CN` 或 `en-US` 运行时文案 |
| `logo` | 无 | 顶栏图片 URL，通常来自 public |
| `repository_url` | 无 | 顶栏仓库链接 |
| `base_path` | `/` | 文档部署路径 |
| `preview` | 无 | 所有 Demo 的 React 包装器 |
| `theme_css` | 无 | 项目主题覆盖文件 |
| `default_theme` | `system` | `light`、`dark` 或 `system` |
| `accent_color` | `#8b5cf6` | 主强调色 |

`source_dir`、`preview` 和 `theme_css` 相对项目根。`logo` 是浏览器访问 URL，不是文件系统路径。

<Callout title="配置优先级" tone="success">
文档命令遵循“命令行参数 → wake.config.toml → 默认值”。例如 <code>--base /preview/</code> 覆盖 <code>[docs].base_path</code>，<code>--port 5174</code> 覆盖开发服务器端口。
</Callout>

## transforms 高级覆盖

```toml
[transforms]
include = []
exclude = []
```

它用于手工强制启用或禁用 Wake 已登记的转换名。普通项目优先使用 Browserslist 自动推导；只有验证某个目标兼容问题时再覆盖，并在代码评审中说明原因。

## hooks

配置模型当前可以解析：

```toml
[hooks]
bootstrap_path = "src/bootstrap.tsx"
```

这个字段是声明式扩展预留项，当前 CLI 主流程没有把它作为普通入口替代。不要依赖它改变应用启动；使用 `[html].entry`。

## 配置排错

1. 运行命令并查看是否有配置 warning；
2. 确认编辑的是实际发现到的 `wake.config.toml`；
3. 检查 `root_dir` 是否改变了路径基准；
4. 把复杂配置缩减到 `[html]` 和 `[react]`；
5. 逐块恢复 alias、proxy、scan 和 docs；
6. 每恢复一块执行一次构建。

这种二分式恢复比同时猜测多个字段可靠。
