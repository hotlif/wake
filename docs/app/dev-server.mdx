## 验证方式

修改组件文本、CSS 和一个依赖模块；页面与样式应更新，控制台不应重复执行副作用。

## 常见错误

- 端口占用：换端口或关闭旧进程。
- 页面空白：先看浏览器第一条异常，再看终端诊断。
- 子路由刷新失败：确认请求到达 Wake，而不是另一个静态服务器。
