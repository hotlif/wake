# 性能与缓存

## 开发性能

保持同一个开发进程运行，让 Wake 复用解析、模块图和代码生成结果。频繁重启会失去内存中的增量状态。

## 生产缓存

内容哈希让未变化文件长期缓存。部署时 HTML 应较快更新，哈希资源可以使用长缓存和 `immutable`。

## 代码分割

用 `import()` 推迟非首屏功能。分割边界应对应真实路由或大型功能，不要为每个小组件创建 chunk。

## 测量方式

记录冷构建、无修改重复构建、单文件修改和生产文件总量。优化前后使用相同入口与依赖锁文件比较。

## 常见误区

- 只比较开发启动时间，不验证修改后的增量时间；
- 清理缓存后声称是热构建；
- 过度分包导致请求和初始化成本上升。
