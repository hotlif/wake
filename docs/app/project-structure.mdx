## 推荐目录

```text
my-app/
├─ public/              # 固定路径资源
├─ src/
│  ├─ entry.tsx         # 创建 React root
│  ├─ app.tsx           # 应用根组件
│  └─ styles.css
├─ package.json
├─ tsconfig.json
└─ wake.config.toml
```

<StepFlow>
  <Step number="SRC" title="参与构建">可分析导入、删除无用代码并重写资源 URL。</Step>
  <Step number="PUB" title="原样复制">适合 favicon、robots.txt 等固定路径文件。</Step>
  <Step number="OUT" title="随时重建">dist 不提交源码分支，也不混入旧构建。</Step>
</StepFlow>

## 入口原则

入口只加载全局样式、创建 React root 并挂载应用。路由、状态和业务页面放入独立模块。

## 验证方式

删除 `dist` 后重新构建；产物必须能完全重建，`public` 资源保持固定路径，源码资源由模块图生成。
