# 资源与 public

跟随组件一起更新的图片适合通过 import 引用；必须保留固定文件名的资源放进 public。

## 进入模块图的资源

组件专属图片和 CSS 引用的字体适合通过相对路径导入。Wake 根据文件内容处理资源，可能内联，也可能输出独立文件，并重写最终引用。

```tsx title="src/Logo.tsx"
import logoUrl from "./logo.svg";

export function Logo() {
  return <img src={logoUrl} alt="项目标志" width={64} height={64} />;
}
```

```ts title="src/assets.d.ts"
declare module "*.svg" {
  const url: string;
  export default url;
}
```

类型声明让 TypeScript 理解资源导入，不负责复制文件。普通 CSS 的 `url('./font.woff2')` 相对 CSS 文件解析；构建后检查重写的 URL，不硬编码哈希文件名。

## 静态 URL 与 Worker

`new URL('./logo.svg', import.meta.url)` 保持 URL 对象语义，将相对文件输出为独立的内容哈希资源，
并使用 `public_path` 生成地址。查询参数和 fragment 保留；文件变化会更新引用。动态参数、远程地址、
被局部变量遮蔽的 `URL` 构造器保持原语义。缺失的静态文件会导致构建失败。
路径中的 UTF-8 百分号编码按 URL 语义解码，例如 `./icon%20x.svg` 引用 `icon x.svg`；无效编码会报错。

```ts title="src/editor.ts"
const logo = new URL('./logo.svg', import.meta.url);
const worker = new Worker(new URL('./editor.worker.ts', import.meta.url), { type: 'module' });
```

静态 Worker 入口由 Wake 独立打包，支持其模块依赖，并按顺序释放每个子构建的编译状态。
Worker 不依赖页面模块表，也不继承页面 federation 上下文；循环 Worker 构建会报错。
开发和生产使用相同构建逻辑。普通资源 URL 始终输出文件，不应用 import 资源的内联阈值。
静态 URL 和 Worker 文件必须位于项目根内，跨根引用会报错。开发与 `build --watch` 在构建前监听
项目内文件，因此 `scripts/` 中的 Worker 和新建的缺失资源也能触发更新；项目内其他文件编辑也可能
触发构建。生成目录、依赖与缓存目录不属于这个默认监听范围。

## public 文件

把 `robots.txt`、固定名称的下载文件或站点图标放到 `public`。代码使用它们的公开 URL；文件内容中的路径不会因为它位于 public 就自动获得模块导入的重写语义。

应用生产构建将 `public/` 的普通文件按原相对路径纳入同一次产物发布，并在返回的文件清单中列为
`asset`；删除的文件在下一次成功构建时清理。根级 `public/index.html` 不作为静态首页复制，首页始终
由选定 HTML 模板生成。其他文件与生成产物重名、包含符号链接或 Windows reparse point 时构建失败，
上一次成功产物保持不变。输出目录不得位于 `public/` 输入目录内。

```html title="链接固定公开文件"
<a href="/guide.pdf">下载指南</a>
```

这条 URL 指向域名根。部署到 `/portal/` 时，项目需要使用相应公开前缀，例如 `/portal/guide.pdf`。不要假定任意字符串 URL 会随 `public_path` 自动改变。

## 选择原则

| 需求 | 推荐方式 |
| --- | --- |
| 图片跟随组件版本变化 | 相对 import |
| CSS 中的字体或背景 | 普通 CSS 的相对 `url()` |
| 必须保留固定文件名 | public 文件 |
| 远程用户上传图片 | 应用使用服务端提供的 URL |

## 验证方式

执行生产构建，查看页面实际的 `src` 与 CSS URL。使用部署前缀打开页面并检查网络面板；小文件内联时不产生独立请求属于正常情况。检查 public 文件是否能按固定路径直接访问。
