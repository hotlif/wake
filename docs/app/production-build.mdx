# 生产构建

<ResultPanel title="可交给静态服务器的 dist" label="完成效果">
你会得到一份可交给静态服务器的 `dist`。以下步骤以[应用入门](/start/create-react-app)的项目和脚本为基础。
</ResultPanel>

## 执行构建

```bash
npm run typecheck
npm run build
```

`build` 脚本执行 `wake build --outdir dist`。Wake 分析入口依赖，生成并优化 JavaScript，抽取 CSS，处理资源，输出 HTML 与 manifest。需要排查压缩后的错误时使用 `npx wake build --outdir dist --sourcemap`。

## 输出目录

`dist` 必须是新目录、空目录或由 Wake 标记拥有的应用输出目录。已有 `.wake-output.json` 用于确认所有权，不应手工伪造或从其他目录复制。

构建失败会报告诊断并保留上一份有效输出。因此“目录存在”不能证明本次成功，自动化必须检查退出码。不要把项目根、源码目录或包含用户文件的目录当作输出位置。

## 验证方式

在项目根运行一个本地静态服务器，例如已经安装 Python 时：

```bash
python -m http.server 8080 --directory dist
```

打开 `http://127.0.0.1:8080/`，验证按钮、样式和图片。该简单服务器用于首页和真实文件检查，不提供 SPA 回退；应用子路由的直接访问需要[部署配置](/app/deployment)。不要用 `file://` 打开 HTML 来替代 HTTP 验证。

检查 Network 面板中的资源返回成功，Console 没有异常，页面没有尝试连接开发 WebSocket。再比较[输出清单](/app/output)中的实际文件。

## 常见错误

- 非空旧目录被拒绝：确认它只是可丢弃产物后自行清理，或使用新的输出目录。
- 新 HTML 搭配旧资源：发布整份输出，不逐个替换不匹配的文件。
- 只构建成功，类型仍错误：生产构建不替代 `typecheck` 和测试。
