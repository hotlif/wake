## 执行构建

```bash
npx wake build --outdir dist
```

## 验证方式

用静态服务器测试首页、直接子路由、动态导入和强制刷新；浏览器不应请求开发 WebSocket。

## 常见错误

不要依赖具体哈希文件名，也不要把旧 dist 与新构建混合部署。
