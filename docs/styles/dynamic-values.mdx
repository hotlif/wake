## 完整示例

```tsx title="meter.tsx"
import { assignVars, createVar, css } from "@crab-dev/css";

const accent = createVar("accent");
const progress = createVar("progress");

const meter = css`
  color: ${accent};
  transform: scaleX(${progress});
  transform-origin: left;
`;

export function Meter({ color, value }: { color: string; value: number }) {
  return <div className={meter} style={assignVars({
    [accent]: color,
    [progress]: value,
  })} />;
}
```

## 用同一组变量表达主题

上例把运行时 color 和 value 写入元素，不重新生成模板。对 value 先限定业务范围，例如把进度限制到 0–1；把外部输入直接当 CSS 值前先做应用层校验。

主题容器也可以一次分配多个颜色变量，让后代规则使用这些引用。变量遵循 CSS 继承：Portal 不在主题容器下时，需要自己的赋值节点或受控挂载位置。文档站自定义 UI 同样遵循此原则。

演示中 Meter 若要直观看见长度，还需设置高度和背景，例如 `height: 8px; background: currentColor;`，再改变 value 验证缩放，而不是只观察空 div。

## 验证方式

修改 `color` 或 `value` 后，元素上的 `--crab-css-*` 值应变化；类名和抽取样式表保持不变。

## 常见错误

- 不要在渲染函数里创建变量，否则名称取决于调用顺序。
- 构建时未知的 props 不能直接插入 `css` 模板。
