# 动态样式

<ResultPanel title="完成后">
  React 只更新元素上的自定义属性；生成类名与抽取样式表保持稳定。

<VisualFigure visual="dynamic-css" alt="React 运行时数值通过 CSS 自定义属性进入静态样式" caption="类名和样式表保持稳定，只有元素上的自定义属性变化。" />

## 完整示例

```tsx title="meter.tsx"
import { assignVars, createVar, css } from "@crab-dev/css";

const accent = createVar("accent");
const progress = createVar("progress");

const meter = css`
  color: ${accent};
  transform: scaleX(${progress});
  transform-origin: left;
`;

export function Meter({ color, value }: { color: string; value: number }) {
  return <div className={meter} style={assignVars({
    [accent]: color,
    [progress]: value,
  })} />;
}
```

## 验证方式

修改 `color` 或 `value` 后，元素上的 `--crab-css-*` 值应变化；类名和抽取样式表保持不变。

## 常见错误

- 不要在渲染函数里创建变量，否则名称取决于调用顺序。
- 构建时未知的 props 不能直接插入 `css` 模板。
