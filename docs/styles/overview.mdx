## 两条样式路径

| 需求 | 普通 CSS | 构建期 CSS-in-JS |
| --- | --- | --- |
| 复用现有样式表 | 直接 import | 按需要逐步迁移 |
| CSS 中相对资源 URL | 由资源管线处理 | 相对 url 暂不支持，移到普通 CSS |
| 组件局部规则 | 自行维护选择器 | css 生成局部类名 |
| 运行时状态 | 类名或自定义属性 | cx、createVar 与 assignVars |
| 全局 reset | 普通 CSS 文件 | 显式顶层 globalStyle |

```bash
npm install @crab-dev/css
```

把依赖声明放在实际导入它的项目中。这个包由 Wake 原生编译，不提供其他构建器的转换插件；不能把未经转换的模板直接交给浏览器执行。

## 按任务开始

从[局部样式](/styles/local-styles)开始，用[类名组合](/styles/composition)表达状态，再用[动态变量](/styles/dynamic-values)传入颜色或进度。页面 reset 放在[全局样式](/styles/global-styles)，运动效果见[动画](/styles/animation)。

遇到样式值无法提取的诊断时，查看[静态求值范围](/styles/static-boundary)，选择常量、CSS 变量或普通 CSS 资源路径。

## VS Code 编辑体验

仓库提供 Crab CSS 扩展，可为 JS、TS、JSX、TSX 中按 import binding 识别的模板提供高亮、补全、悬停、颜色与诊断。别名 import 可识别，局部同名变量不应被当作样式 API。

编辑器辅助不是构建前提。TypeScript 定义、引用与重命名继续由其语言服务负责；最终以项目类型检查和 Wake 构建结果验证。高亮和补全用于辅助编辑，发布前仍需执行构建。
