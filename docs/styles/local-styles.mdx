## 编写完整样式

```tsx title="card.tsx"
import { css } from "@crab-dev/css";

const card = css`
  display: grid;
  gap: 12px;
  padding: 16px;

  &:hover { border-color: #7c3aed; }
  & > h2 { margin: 0; }

  @media (width < 640px) {
    padding: 12px;
  }
`;

export function Card() {
  return <article className={card}><h2>标题</h2></article>;
}
```

## 验证方式

在 hover 和窄屏状态下检查边框与间距；CSS 中只应出现生成类名，不应包含运行时模板。

## 常见错误

- 全局副作用使用 `globalStyle`，不要藏在局部 `css` 中。
- `css` 模板暂不接收相对 `url()`；需要资源重写时，把这条规则移到普通 CSS 文件。
