## 编写完整样式

```tsx title="card.tsx"
import { css } from "@crab-dev/css";

const card = css`
  display: grid;
  gap: 12px;
  padding: 16px;
  border: 1px solid transparent;

  &:hover { border-color: #7c3aed; }
  & > h2 { margin: 0; }

  @media (width < 640px) {
    padding: 12px;
  }
`;

export function Card() {
  return <article className={card}><h2>标题</h2></article>;
}
```

## 在应用中使用

先安装 `@crab-dev/css`，将 Card 从模块中导出，在应用入口或页面中 import 并渲染 `<Card />`。顶层 css 模板在构建时变成规则和类名，不应放进点击事件中尝试即时生成 CSS。

嵌套的 `&` 表示当前生成类，`& > h2` 只选择直接子标题。上例先设置透明边框，hover 再改变 border-color，因此交互时能看见颜色变化而不改变盒子尺寸。

页面窄于 640px 时 padding 应由 16px 变为 12px。检查元素计算样式与媒体查询命中情况，不能只靠肉眼判断间距是否改变。

## 验证方式

在 hover 和窄屏状态下检查边框与间距；CSS 中只应出现生成类名，不应包含运行时模板。

## 常见错误

- 全局副作用使用 `globalStyle`，不要藏在局部 `css` 中。
- `css` 模板暂不接收相对 `url()`；需要资源重写时，把这条规则移到普通 CSS 文件。
