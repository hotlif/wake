## 先记住这两点

`describe`、`test`、`expect` 等名称需要从 `@crab-dev/wake/test` 导入；React 辅助工具来自 `@crab-dev/wake/test/react`。API 具有熟悉的写法，但第三方测试框架的配置、插件、Mock 提升或结果格式不能直接迁移。

DOM 环境适合快速交互测试，真实样式、布局、截图和浏览器敏感行为使用 browser 环境。不要用 DOM 模拟环境的结果推断实际像素位置。升级 Wake、React 或浏览器后重新运行项目代表性测试。
