# 第一个文档站

本教程创建一个小型组件库文档。你会写一个 Button、一个 Demo、一篇 MDX 页面，以及全局预览包装器。

## 最终目录

```text
my-ui/
├─ docs/
│  ├─ components/
│  │  ├─ button.mdx
│  │  └─ demos/
│  │     └─ basic.demo.tsx
│  ├─ index.mdx
│  ├─ preview.tsx
│  └─ theme.css
├─ src/
│  └─ button.tsx
├─ package.json
└─ wake.config.toml
```

`*.mdx` 是读者看到的页面，`*.demo.tsx` 是可以运行和查看源码的示例，`src` 放真实组件，`preview.tsx` 包装所有 Demo，`theme.css` 定制文档站外观。

## 1. 准备依赖和脚本

```json title="package.json"
{
  "name": "my-ui",
  "private": true,
  "type": "module",
  "scripts": {
    "docs:dev": "wake docs dev .",
    "docs:build": "wake docs build . --outdir docs-dist"
  },
  "dependencies": {
    "react": "^19.0.0",
    "react-dom": "^19.0.0"
  },
  "devDependencies": {
    "@types/react": "^19.0.0",
    "@types/react-dom": "^19.0.0",
    "typescript": "^6.0.0"
  }
}
```

执行 `npm install`。Wake Docs 使用项目自己的 React，不会安装第二份 React。

## 2. 配置文档站

```toml title="wake.config.toml"
[docs]
source_dir = "docs"
title = "My UI"
description = "团队 React 19 组件使用指南"
locale = "zh-CN"
base_path = "/"
preview = "docs/preview.tsx"
theme_css = "docs/theme.css"
default_theme = "system"
accent_color = "#7c3aed"

[dev_server]
host = "127.0.0.1"
port = 5173
open = false

[react]
enabled = true
jsx_import_source = "react"
```

`locale = "zh-CN"` 会让搜索、Demo 按钮和状态标签使用中文。主题支持 `light`、`dark` 和 `system`。

## 3. 编写真实组件

```tsx title="src/button.tsx"
import type { ButtonHTMLAttributes, ReactNode } from "react";

export interface ButtonProps
  extends ButtonHTMLAttributes<HTMLButtonElement> {
  /** 按钮视觉样式 */
  appearance?: "primary" | "secondary";

  /** 是否显示处理中状态
   * @default false
   */
  loading?: boolean;

  /** 按钮内容 */
  children: ReactNode;
}

export function Button({
  appearance = "primary",
  loading = false,
  disabled,
  children,
  ...rest
}: ButtonProps) {
  return (
    <button
      {...rest}
      data-appearance={appearance}
      disabled={disabled || loading}
    >
      {loading ? "处理中…" : children}
    </button>
  );
}
```

这个类型稍后可以被 `<API>` 转换成 Props 表格。JSDoc 文本成为属性说明，`@default` 成为默认值。

## 4. 创建 Demo

```tsx title="docs/components/demos/basic.demo.tsx"
import React from "react";
import { Button } from "../../../src/button";

export const meta = {
  title: "基础用法",
  description: "默认按钮和禁用状态",
  background: "surface",
  padding: "md",
  isolation: "iframe",
};

export default function BasicDemo() {
  return (
    <div style={{ display: "flex", gap: 12 }}>
      <Button onClick={() => window.alert("已提交")}>提交</Button>
      <Button appearance="secondary" disabled>不可用</Button>
    </div>
  );
}
```

Demo 必须默认导出 React 组件。Wake 会把它放进 iframe，使文档页面样式与示例运行环境彼此隔离。

````mdx title="docs/components/button.mdx"
# Button 按钮

Button 用于提交、确认和触发即时操作。按钮文字应描述操作结果，
例如“保存设置”，不要只写“确定”。

## 基础示例

<Demo src="./demos/basic.demo.tsx" />

## 什么时候使用

- 用户需要主动触发操作时；
- 操作结果明确并且能够立即反馈时；
- 表单需要提交或取消入口时。

## API

<API
  source="../../src/button.tsx"
  symbol="ButtonProps"
  component="Button"
/>
````

`Demo.src` 和 `API.source` 都相对当前 MDX 文件解析。最常见错误是多写或少写一层 `../`。

## 7. 添加 Preview 包装器

```tsx title="docs/preview.tsx"
import React from "react";

export default function Preview({
  children,
}: {
  children: React.ReactNode;
}) {
  return (
    <div style={{
      minHeight: 96,
      display: "grid",
      placeItems: "center",
      color: "var(--text)",
    }}>
      {children}
    </div>
  );
}
```

真实项目可以在这里加入 ThemeProvider、国际化 Provider、状态容器和组件库全局 CSS。所有 Demo 共用这一层。

## 8. 添加主题 CSS

```css title="docs/theme.css"
:root {
  --docs-brand: #7c3aed;
}

.mdx-content a {
  color: var(--docs-brand);
}

.demo-stage {
  border-radius: 12px;
}
```

主题 CSS 是项目级覆盖层。优先修改公开 CSS 变量和稳定类名，不要依赖构建后生成的 hash 类名。

## 9. 启动并验证

```bash
npm run docs:dev
```

按顺序检查：

1. 侧栏出现“开始”和“基础组件”；
2. Button 页面显示 Preview；
3. Demo 按钮可以运行；
4. 切换“源码”能看到 Demo 原文件；
5. API 出现 `appearance`、`loading` 和 `children`；
6. 修改 MDX、Demo 或 `ButtonProps` 后页面自动更新；
7. 按 `Ctrl+K` 或 `⌘K` 能搜索标题和 Props。

## 10. 生产构建

```bash
npm run docs:build
```

`docs-dist` 会包含每条路由的 HTML 外壳、`404.html`、带 hash 的 JS/CSS 和 `manifest.json`。

<Callout title="不要编辑生成文件" tone="warning">
<code>.wake/docs/generated</code> 和 <code>docs-dist</code> 都是生成结果。修改应发生在 MDX、Demo、组件源码、Preview 或主题 CSS 中。
</Callout>
