# 术语表

## 构建与文档术语

| 术语 | 含义 |
| --- | --- |
| asset（资源） | 图片、字体、CSS 等非 JavaScript 输出 |
| bundler（打包器） | 解析模块依赖并生成可部署文件的工具 |
| chunk | 一个可独立加载的 JavaScript 输出单元 |
| entry（入口） | 模块图开始解析的文件 |
| Live Reload | 源码成功重建后刷新整个浏览器文档；不保留页面内存状态 |
| module graph（模块图） | 模块及其静态、动态依赖组成的图 |
| Tree Shaking | 删除未被使用的导出和代码 |
| source map | 生成代码位置到源文件位置的映射 |
| CSS extraction | 把模块中的样式汇总为普通 CSS 文件 |
| hydration | 服务端 HTML 在浏览器中接管为可交互 React 树 |
| peer dependency | 要求由使用项目提供的共享 npm 依赖 |
| MDX | 可嵌入 JSX 的 Markdown 内容格式 |
| Demo | 在隔离环境中运行的文档示例 |
| Frontmatter | MDX 顶部描述标题、类型和状态的 TOML 块 |
