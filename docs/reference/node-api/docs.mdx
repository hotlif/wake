# Node.js Wake Docs API

```ts
import { buildDocs, startDocsDevServer } from "@crab-dev/wake";
```

首次使用请先阅读[文档站教程](/wake-docs/create-site)。

## `buildDocs(options)`

```ts
const result = await buildDocs({
  cwd: process.cwd(),
  outdir: "docs-dist",
  basePath: "/docs/",
  mode: "site",
});
```

结果在普通 `BuildResult` 基础上增加 `routes`、`mode`、`demos` 和必有的 `workspaces`。
非聚合构建返回空 `workspaces`；聚合构建中的每项包含 `name`、绝对 `root`、`basePath`、
`mode: "components"`、`presentation` 和 Demo 数量。`routes` 与 `demos` 始终只描述主项目。

## `startDocsDevServer(options)`

返回与应用开发服务器相同的 `DevServer`，额外接受 `mode: "site" | "components"`。服务关闭、事件和取消语义与 `startDevServer` 一致。

`site` 模式自动读取 `[[docs.workspace]]`。聚合服务器会发送 `workspaceState`，工作区重建的
`rebuildStart` 与 `rebuilt` 还包含 `workspace` 和 `basePath`。

## `testDocs(options)`（experimental）

```ts
import { testDocs } from "@crab-dev/wake";

const result = await testDocs({
  root: process.cwd(),
  themes: ["light", "dark"],
  viewports: [{ width: 1280, height: 720 }, { width: 390, height: 844 }],
  updateSnapshots: false,
});
if (!result.success) process.exitCode = 1;
```

构建当前单站并验证全部 Demo 的初始渲染，返回与 `runTests()` 相同的 `TestRunResult`。
默认采用示例中的矩阵；主题必须为不重复的 light/dark，视口为 1–8 个不重复尺寸，每维 1–8192。
支持 `browserPath`、`headful` 和 `signal: AbortSignal`。缺失基线默认失败；显式
`updateSnapshots: true` 才创建或更新。报告中的 artifacts 包含基线、received 和 HTML 差异路径。
配置、构建及宿主错误拒绝 Promise；截图不匹配和 Demo 运行错误返回 `success: false`。
首版不支持工作区聚合、watch 或交互步骤，详情见 [CLI 参考](/reference/cli/docs)。
