# Wake Test API

Wake Test 为 experimental，API 必须显式导入。教程从[首个测试](/testing/first-test)开始；本页用于查询签名和行为，不承诺其他 runner 的配置或插件兼容。

## 测试与断言

```ts
import { describe, test, expect, beforeEach, afterEach, mock, clock, network } from "@crab-dev/wake/test";
```

| API | 行为 |
| --- | --- |
| test / it、describe | 用例与分组，支持 only、skip、each；test.todo 记录待办 |
| beforeAll / beforeEach / afterEach / afterAll | 同步或返回 Promise 的生命周期回调 |
| expect | 值、结构、数值、字符串、集合、属性、异常、Promise 与 Mock 断言 |
| expect.extend | 安装自定义 matcher |
| expect.assertions / hasAssertions | 检查断言执行数量 |

测试参数为 `test(name, callback, { timeout: 10_000 })`。不支持 done 回调、test.concurrent、focused aliases 或默认导出。异步 matcher 必须等待；完整类型由安装包 `test.d.ts` 提供。

## 模块 Mock

| API | 行为 |
| --- | --- |
| mock.fn、spyOn、replaceProperty | 创建函数替身、监视或替换属性 |
| implement / implementOnce | 设置实现 |
| return / returnOnce、resolve / resolveOnce、reject / rejectOnce | 设置同步值或 Promise 结果 |
| clear、reset、restore | 清调用、重置或恢复 |
| mock.module | 注册模块工厂，工厂可异步 |
| mock.import | 在注册后加载目标模块 |
| mock.actual | 加载真实模块 |
| mock.isolate | 使用新模块缓存和工厂实例执行回调 |

模块 Mock 不提升；必须先注册，再通过 mock.import 加载目标。已执行的静态 import 不会改变。没有 automock 或 `__mocks__` 目录。spy 和替换属性在每个测试后恢复；详细例子见[Mock 教程](/testing/mocks)。

## 时钟与网络

`await clock.fake(options?)` 启用异步虚拟时钟，支持 now、timerLimit 和排除项。advanceBy、advanceTo、runNext、runAll、flushMicrotasks 均需要等待；restore 返回真实时间。React 更新会经过相应 act 检查点，不提供旧式 timer 模式。

`network.route(matcher, handler)` 和 `network.allow(matcher)` 返回释放函数。matcher 可使用 URL、字符串、正则、方法/URL 对象或请求判断函数。handler 返回 Response 或含 status、headers、body、delayMs 的响应对象。

默认拒绝真实外部网络。allow 是显式的测试内许可，allow_hosts 提供项目级许可。每个测试后路由、许可和记录会重置；`network.requests()` 查看记录，`network.reset()` 主动清理。完整例子见[时间与网络](/testing/time-and-network)。

## 快照与截图

`toMatchSnapshot(propertyMatchers?, hint?)` 保存外部 Wake 文本快照，支持可序列化的稳定结果和属性 matcher。对象键与 DOM 属性确定排序，文本和注释保留语义。不支持 inline snapshots，也不改写测试源码。

`await expect(document).toMatchScreenshot('page')` 截取 browser 视口；Element 截取可见区域。DOM 环境使用此 matcher 会返回浏览器错误。基线按操作系统、架构、Chromium 身份、视口、设备比例、语言、时区、主题、减少动态效果和 headless 状态隔离。

`--update-snapshots` 用于有意更新，普通 CI 不应自动接受变化。截图首期精确比较，不提供容差、字体归一化、跨 profile 比较或全页拼接。失败保留原基线并生成实际 PNG 与 HTML diff。参见[快照教程](/testing/snapshots)。

## React 测试工具

```tsx
import { render, renderHook, screen, within, userEvent, fireEvent, act, waitFor, cleanup } from "@crab-dev/wake/test/react";
```

| API | 返回或用途 |
| --- | --- |
| render(ui, options?) | Promise，结果含 container、rerender、unmount、asFragment、debug |
| renderHook(callback, options?) | Hook 结果与重渲染、卸载操作 |
| screen / within(element) | 按 role、文本、标签等查询 |
| userEvent.setup() | click、type、keyboard 等可等待交互 |
| fireEvent | 直接分发指定事件 |
| act / waitFor / waitForElementToBeRemoved | 等待更新、断言成立或元素移除 |
| cleanup / prettyDOM | 卸载测试树、格式化 DOM |

render options 包括 container、baseElement、hydrate、strict、wrapper、identifierPrefix 和 React 错误回调。操作使用异步 act，默认测试后清理挂载。react 与 react-dom 必须来自匹配的项目实例、版本相同且满足 `>=19.2.8 <19.3.0`。

DOM 和 browser 的选择见[环境教程](/testing/environments)，运行参数见[test 命令](/reference/cli/test)。
