# 开发服务器配置

```toml
[dev_server]
server = "http"
host = "127.0.0.1"
port = 5173
open = false

[[dev_server.proxy]]
context = ["/api"]
target = "http://127.0.0.1:3000"
change_origin = true
ws = false

[dev_server.proxy.path_rewrite]
"^/api" = ""
```

首次使用请先阅读[开发服务器教程](/app/dev-server)。

## 字段

| 字段 | TOML 类型 | 默认行为 | 说明 |
| --- | --- | --- | --- |
| `server` | 字符串 | HTTP | 预留的协议字段；当前仍以 HTTP 启动 |
| `host` | 字符串 | `127.0.0.1` | 监听地址 |
| `port` | 整数 | CLI 使用 `5173` | 配置端口；CLI 选项优先，见下文 |
| `open` | 布尔值 | `false` | 启动后打开浏览器 |
| `proxy` | 表数组 | 空数组 | 按声明顺序执行的代理规则 |
| `context` | 字符串数组 | 空数组 | 当前代理匹配的路径前缀；配置规则时显式提供 |
| `target` | 字符串 | 空字符串 | 后端地址；配置规则时提供完整 URL |
| `ws` | 布尔值 | `false` | 是否代理 WebSocket |
| `change_origin` | 布尔值 | `false` | 是否重写请求 Host |
| `path_rewrite` | 字符串映射表 | 空表 | 转发前的路径替换 |

当前 `wake dev` 的 `--port` 自带默认值 `5173`，会覆盖 TOML 中的端口。需要其他端口时执行
`wake dev . --port 3001`，不能只修改此处的 `port`。Node API 的端口选项见
[开发服务器 API](/reference/node-api/dev-server)。

代理仅用于开发，不写入生产产物。生产转发由部署平台配置。

Live Reload 在开发服务器中始终启用：成功重建后浏览器刷新整个页面，构建失败时显示诊断且不刷新。
它不是模块 HMR，也没有 `hmr`、`hot` 或 `live_reload` 配置项。`[dev_server]` 出现未列出的字段会
作为配置错误拒绝，不会被静默忽略。参见 [Live Reload](/app/live-reload)。
