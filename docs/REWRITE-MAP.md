## 本轮阅读体验调整

逐页复核原有 83 个页面的用途描述与正文，统一教程的完成效果、操作、验证和排错顺序。
新增隔离组件独立教程后，共有 84 个公开页面；原有页面 URL 保留。
首页、章节入口和导航按任务重新组织，长参考示例可展开，精确 API、默认值和错误码继续保留。
本站阅读样式集中在 `site/reading.css`，覆盖桌面、手机和明暗主题，并排除自定义 UI 与 Demo 边界。
