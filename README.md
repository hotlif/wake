# Wake

Wake is a Rust-native web compiler, bundler, development server, and component
documentation builder.

The Rust CLI is available as `wake`. Node.js users can install the prebuilt
native package:

```sh
npm install --save-dev @crab-dev/wake
npx wake build
```

See [the npm package documentation](npm/wake/README.md). Legacy migration notes
are kept under docs/migrations/.
