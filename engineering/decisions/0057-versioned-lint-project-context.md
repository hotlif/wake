# ADR 0057: 带版本的 lint 项目上下文

- Status: accepted
- Date: 2026-09-13
- Amended by: [ADR 0058](0058-lint-watch-lifecycle.md)
- Amended by: [ADR 0063](0063-lint-module-graph-snapshots.md)

## Context

watch 和编辑器会在旧分析运行期间接收新源码。单次 stdin 不能表示多个未保存文件，也不能表达
取消、关闭或旧结果失效。项目生命周期应由共同应用入口拥有，而不是各前端复制。

## Decision

`wake_app::LintContext` 固定创建时的规范项目根和请求配置，保留按规范相对路径登记的未保存文档。
根可以在原位置重建为普通目录，但不能通过替换根或祖先的符号链接/junction 重定向至另一项目。
更新/关闭文档要求严格递增的安全整数版本；关闭保留版本墓碑，旧事件不能重新打开过期文档。
每次检查重新读取项目配置和磁盘文件，未保存文本覆盖同路径文件，并允许尚未保存的新文件。
忽略和路径筛选保持与单次项目检查相同；内存源码不进入持久化诊断缓存。

每次请求、文档更新、显式失效或关闭都推进项目代次并取消已有检查。每个上下文最多一个分析执行。
请求先同步取得代次与文档快照；Node 工作线程的调度顺序不能改变请求的新旧顺序。
等待中的旧请求再次验证取消状态后退出。结果携带代次与所检查的文档版本，在最后
状态锁内验证后返回。前端必须携带这些身份，不能把迟到结果无条件显示为当前版本。

上下文只做只读检查，允许应用已有基线，拒绝生成/清理基线、源码修复、stdin、配置解释和规则目录。
修复继续使用显式单次入口。关闭先取消检查，再等待正在执行的工作完成；重复关闭幂等。
Node 清理钩子和资源析构负责同一上下文的取消/关闭，不能留下后台请求。
Node 适配器使用每个上下文一个 Rust 工作线程、有界的最新待执行请求/结果槽及 JS 主动读取。
不在 Worker 退出期间从原生异步完成回调解析 JS Promise；真实强制退出测试已复现此类回调崩溃。
显式关闭由 JS 等待线程完成，环境清理钩子同步取消并回收线程；完成数据不持有 JS 值或回调。
单次 Node lint 同样采用可取消、可回收的只读结果槽，公开 Promise 仍由 JS 包装提供；其私有原生
handle 不作为 npm 公共 API。一次性操作结束后回收线程，不延长项目资源生命周期。

此决策固定手动项目上下文和原始输入覆盖契约；文件事件后端和自动调度尚需独立实现及验证，
不能将此记录当作 watch 已完成。既有 build/dev 的 ADR 0037 所有权保持有效。

## Invariants

- 不把编译器 overlay、合成文件或单个 stdin 当作多个未保存源码的替代品。
- 任一检查使用创建时复制的文档集合；后续更新不能改变已经借用的源码。
- 旧代次不进入结果提交；关闭后不能开始检查、更新或失效操作。
- 请求取消同时终止等待与正在执行的工作，不写源码或基线。
- CLI、Node、watch 和后续 LSP 共用相同项目分析与坐标转换。

## Evidence

应用上下文用例覆盖多文档覆盖、虚拟新文件、严格版本、关闭后磁盘回退、配置重载、取消及并发旧结果。
Node 真实 addon 验证 ESM/CJS、AbortSignal、dispose 和资源清理。

## Consequences

单次检查接口保持兼容。上下文暂不保留 AST 或类型服务，不以保留一个对象宣称完整增量分析。
版本化输入及结果可以被后续 watch/LSP 调度复用。

## Validation

失败测试先行；上下文、单次 lint/cache/baseline 回归；真实 Node 生命周期、类型、Clippy、架构和文档门禁。
