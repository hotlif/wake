# Wake 0.1.52

接续未发布的 0.1.51 候选并保留其标签。依据 ADR 0083 正式审查 Linux Chrome 157 的官方镜像，
仅扩展 Linux 实验性准入；完整浏览器门禁及 stable readiness blocked 策略保持。

本补丁修复 `component_scan` 在导入扫描模块时提前启动全部页面导入的问题。

- `component` 保存 `() => import(...)` 加载函数；导入扫描模块、遍历菜单或路由元数据、读取或解构函数不启动页面导入。
- 调用时加载目标页面及必要依赖，未访问页面独占的 JS、CSS 不会因扫描提前加载。重复调用复用模块执行结果。
- `name`、项目根相对 `path`、TOML `frontmatter`、路径排序与 `generate_source` 保持；源码内联仍是文本，不执行页面。
- 开发服务新增、删除扫描页面或修改 frontmatter 后继续通过 Live Reload 更新扫描结果。

这是 `component` 的调用契约变更：从 `await page.component` 迁移为 `await page.component()`，
从 `.component.then(...)` 迁移为 `.component().then(...)`，并将类型改为 `() => Promise<页面模块类型>`。
React `lazy` 可直接接收加载函数；其他路由 lazy 回调应在被调用时执行加载函数并适配模块导出。
不保留会提前启动导入的旧 Promise 兼容模式。应用路由、后台标签页和类型声明须由消费者同步。
