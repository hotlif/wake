# Wake 0.1.48

本版本接续在 npm 发布前取消的 [0.1.47 候选](0.1.47.md)，包含该候选的全部功能。

- 开发与生产只读取同一个 HTML 模板：显式 `html.template`，否则项目根 `index.html`；默认文件缺失时用内置外壳，不再隐式搜索 `public/index.html`。
- `public/` 资源与应用输出原子发布；开发代理支持 SSE 流式转发和 WebSocket 升级、双向帧及关闭原因。
- 静态 Worker 与资源 URL 由原生构建管线处理，带内容哈希、缓存失效和项目根监听；Worker 独立顺序构建，引用限定项目根内。
- 构建、库打包、构建上下文和开发服务支持 API `define` 覆盖；库输出增加受限同步 ESM，以及带 source map 偏移的 `banner` / `footer`。
- 包含 0.1.46 后的 lint 扩展授权、Docs 视觉测试、测试工程控制与源码覆盖率等已有更新，维持各自的 experimental 能力边界。
- 修正 source map 注释拼接造成的多余换行；静态资源和 Worker 的根边界按文件系统真实身份比较，避免误拒绝 Windows 长路径与 8.3 短路径别名。

本次根据官方不可变镜像清单，新增 Linux Chromium 主版本 156 和 macOS arm64 主版本 157 的准入证据，
并同步 CI、发布前后验证矩阵。仍要求系统浏览器、CDP 真实版本、headless 和对应平台功能测试；
未知主版本继续拒绝，stable readiness 仍为 blocked。详见 [ADR 0080](../decisions/0080-reviewed-linux-156-macos-arm64-157.md)。

功能验证沿用 0.1.47 候选的本地证据；本次另外验证浏览器准入回归、60 项架构测试、完整 Node API 测试，
以及库输出、资源身份边界与开发服务测试。
标签工作流负责完整 workspace 测试、五平台构建、八个不可变 tarball 审计和发布前后干净安装检查。
本次发布八个 npm 包，不发布 VS Code 扩展。
