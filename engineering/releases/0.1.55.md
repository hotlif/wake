# Wake 0.1.55

本版本新增实验性浏览器内构建和本地预览 SDK，契约由 ADR 0084 定义。

- Worker/WASM 复用 Wake 的 BuildSession、编译器与 resolver，接收完整虚拟文件快照。
- 返回 JS、CSS、图片、延迟分块、source map 与 Federation manifest，原生与 WASM 产物逐字节对照。
- Service Worker 按页面与会话保存不可变资源；prepare/commit/dispose 支持最新结果切换、失败回滚和旧视图资源保留。
- 共享依赖绑定宿主真实 provider 身份，验证开发及生产 React 宿主、Hooks、TSX、CSS Modules 和 Wake CSS。
- 主包包含版本匹配 WASM、浏览器和 Service Worker 类型入口；实际 npm tarball 浏览器消费纳入发布门禁。

宿主负责供应依赖、共享 provider、挂载回调及 Worker/WASM/Service Worker 部署。
首版不支持自动安装依赖、远程 Federation 依赖、共享 fallback 或 isolated expose，不保证 Fast Refresh 状态保持。
WASM 约 6.8 MB 未压缩，主包 packed 预算为 4 MiB，WASM 单独预算为 10 MiB。

0.1.53 候选因 PnP 声明投影未区分部署资源而停止；0.1.54 候选因 macOS 测试 HTTP 服务继承非阻塞
socket 而取消。两者均未执行 npm publish，标签保留。PnP 检查现在仅精确排除三个资源入口，其他 API
仍要求 types；独立项目覆盖浏览器 SDK 和 handler 类型消费。测试服务显式恢复阻塞模式，默认回归
强制非阻塞 accepted stream、延迟请求和读取，并验证 32 MiB 响应完整性。

本地实际 tarball 也通过全部六项浏览器/socket 测试。
