# Wake 0.1.46

本次发布增加原生构建卡顿诊断，并改善旧版本输出目录缺少所有权标记时的恢复提示。

- 使用 `--progress` 或 `WAKE_PROGRESS=1` 开启 stderr 诊断，自动采用 plain 界面，保留 `WAKE_TIMING`。
- 每次构建、watch/dev 重建和 Docs 按需构建分别关联目标、父子步骤与共享 worker，避免并发构建串号。
- 心跳显示正在执行的模块、优化 pass 和迭代轮次，并覆盖 CSS、Source Map 与 Docs 源文件处理。
- 每次构建汇总墙钟总时长、步骤次数及累计/平均/最大耗时，保留最慢十个模块操作。
  步骤包含子步骤，并行累计时间可能超过墙钟时间，不能直接相加；步骤退出不表示成功。
- 关闭诊断时不构造详情或启动采样线程；开启诊断不改变产物、缓存身份、发布事务或取消语义。
- 遇到旧版本生成、缺少 `.wake-output.json` 的目录时，提供更明确的备份、重新构建和更换输出目录提示。

功能改动已通过受影响 Rust 测试、Rust/npm CLI、Clippy、格式、架构和文档检查，并用重新构建的
原生绑定验证 npm 入口。发布工作流继续执行完整测试、多平台构建、产物审计和发布前后干净安装验证。

`v0.1.46` 同步发布八个 npm 包。本次不发布 VS Code 扩展。
