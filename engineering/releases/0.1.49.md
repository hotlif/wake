# Wake 0.1.49

本补丁修复 Monaco 位于项目根外 Yarn PnP 缓存时，包内静态 URL 被 WAKE0304 拒绝的问题。

- 允许当前 PnP 安装图中的依赖引用自身包内资源和 Worker；仍检查同一 locator 与物理包根，拒绝跨包和链接逃逸。
- 在候选构建前注册 PnP 包归档与目录监听；归档替换会刷新模块和资源缓存，失败构建保留上一版发布产物。
- 增加真实 `monaco-editor@0.57.0` fixture，验证构建成功、资源字节一致、发布 URL 正确且不泄漏缓存路径。

本地已通过 resolver、bundler、app 完整默认测试和全 target Clippy，真实 HTTP Worker 监听回归、
PnP 差分一致性、架构和文档检查。归档替换、删除与恢复覆盖了保留会话的发布路径。
完整 Monaco 编辑器浏览器运行和默认 ignored 测试不在本地验证范围内。

标签工作流负责完整 workspace 测试、五平台构建、八个不可变 tarball 审计及发布前后干净安装检查。
本次发布八个 npm 包，不发布 VS Code 扩展。资源边界依据 [ADR 0081](../decisions/0081-pnp-package-resource-boundaries.md)。
