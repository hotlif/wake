# Wake 0.1.45

本次发布修复 `cx()` 编译后的变量绑定丢失问题。此前，包含局部变量、函数参数或导入绑定的
调用可能在构建成功后抛出 `ReferenceError`，或者因遮蔽而产生错误类名。

- 含变量、条件、数组、对象或嵌套表达式的 `cx()` 调用保留原 AST 和小型运行时，保持导入、
  重命名、存活分析、TDZ 和参数求值顺序。
- 只将可证明安全的简单字面量调用折叠为字符串，避免引入受局部作用域影响的 `Boolean` 引用。
- 新增实际执行构建产物的回归测试，覆盖 readable/minified、tree-shaking 开关、词法遮蔽、
  嵌套样式、参数副作用和 retained rebuild。

修复已通过完整 workspace 测试（2525 项通过、73 项显式忽略）、全 workspace Clippy、
格式检查、文档检查和 85 个路由的文档构建。发布工作流继续执行多平台构建、产物审计以及
发布前后的干净安装验证。

`v0.1.45` 同步发布八个 npm 包。本次不发布 VS Code 扩展，也不改变公共 CSS API 的结果契约。
