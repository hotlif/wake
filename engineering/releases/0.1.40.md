# Wake 0.1.40

本版本新增实验性原生 Lint 产品入口。完整 P0–P7 计划仍在实施，当前能力与限制以
[Lint 实施契约](../LINT.md) 和 [命令参考](../../docs/reference/cli/lint.mdx) 为准。

- `wake lint` 与 Node API 提供 77 条 JS、TS、React、无障碍、模块、风格和类型规则，支持
  声明式配置、预设、文件覆盖、诊断抑制、基线、缓存、监听以及有界并发。
- 支持安全修复预览与写回、Markdown 代码块诊断、LSP quick-fix，以及源码形式的 VS Code
  客户端。编辑器客户端仍需单独构建和配置语言服务器，本次 npm 发布不包含 VSIX。
- 发布独立的 `@crab-dev/wake-lint-sdk`，提供冻结输入、诊断、UTF-8 编辑和协议校验；
  CLI/编辑器自动加载第三方规则尚未接入，也不执行 ESLint JavaScript 插件或配置。
- 编译器保留更多原始源码和语义事实，字符串、模板、导入属性及类型模块请求按 UTF-16
  码元保留。运行时静态模块说明符与部分高级类型字符串边界仍有已记录限制。
- 类型规则需要项目显式配置 TypeScript 7.0.2 原生编译器；不完整的类型证据会报告分析错误。

发布由 `v0.1.40` 标签触发既有 npm 流水线。五个平台的构建、tarball 审计和消费检查通过后，
依次发布平台包、CSS、Lint SDK 与主包，随后执行注册表安装验证。
