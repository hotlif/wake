# Wake 0.1.44 / Crab CSS VS Code 0.1.4

本次发布修复 CSS 编译、CSS Modules 和编辑器中已复现的五类问题。

- 局部 `css` 模板允许 `@starting-style`；嵌套展开保留父选择器、条件和声明顺序。
- `@scope` 保留原生嵌套位置及其起点、终点和内部作用域语义。局部动画名称引用仍保持一致。
- CSS Modules 在 scope 起点和终点使用同一局部类名映射，支持转义与显式 global/local。
- 多选择器、多个 `&`、复杂父选择器、类型选择器及伪元素遵循 CSS Nesting 的集合匹配语义。
- `@position-try`、16 种页边距规则和 6 种字体特性值子规则获得正确声明上下文；自定义字体
  描述符不会被误报或补全为普通 CSS 属性。

本地已新增 12 项回归测试，并通过 219 个相关 Rust 测试、Rust 1.95 Clippy、文档检查、
6 个扩展契约测试、VS Code 1.96.4 Extension Host 和 Chrome 153 的原生/编译输出对照。
发布工作流还会执行完整 workspace、平台构建、产物审计和发布前后的干净安装验证。

`v0.1.44` 发布八个 npm 包；`vscode-css-v0.1.4` 独立发布五个平台的 VSIX 到 GitHub Releases。
扩展不发布到 Marketplace。保留的原生 CSS 功能仍需目标浏览器支持；本版本未新增
`@function`、`@when` 等实验性规则支持，也不改变此前 Lint 产品的实验性边界。
