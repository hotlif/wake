# Wake 0.1.53

状态：候选未发布。发布运行 43803755794 在 PnP 声明投影检查阶段失败，尚未进入 npm publish；保留标签并由 0.1.54 接续。

本版本新增实验性浏览器内构建和本地预览 SDK；契约由 ADR 0084 定义。

- `@crab-dev/wake/browser` 在 Worker/WASM 中复用 Wake 的 BuildSession、编译器与 resolver，接收完整虚拟文件快照。
- 返回 JS、CSS、图片、延迟分块、source map 与 Federation manifest；原生与 WASM 产物进行逐字节对照。
- Service Worker 资源存储按页面与会话隔离，保留旧视图所需资源；预览使用 prepare/commit/dispose 交接，不触发编辑器整页刷新。
- 共享依赖绑定宿主已注册 provider 的真实身份，覆盖开发与生产 React 宿主、Hooks、TSX、CSS Modules 和 Wake CSS。
- 提供浏览器与 Service Worker 独立类型入口、WASM 打包和实际 npm tarball 浏览器门禁。

宿主需部署版本匹配的 Worker/WASM 与 Service Worker，供应固定依赖文件及共享 provider。
首版不支持自动安装依赖、远程 Federation 依赖、共享 fallback 或 isolated expose；不保证 Fast Refresh 组件状态保持。
主包增加约 6.8 MB 未压缩 WASM；主包 packed 预算为 4 MiB，WASM 单独预算为 10 MiB。

实现阶段已完成全 workspace 默认测试、全 target Clippy、WASM Clippy、架构、声明、文档和打包检查。
本地真实浏览器为 Windows Chrome 157.0.8103.51，并验证了实际 npm 包和两种 React 宿主模式。
这些本地功能结果不改变已审查的 CI 浏览器 major 矩阵，也不代表 Firefox、Safari 或跨平台验证完成。

发布仍执行五平台构建、八包审计、15 组发布前后消费及最低 glibc 检查。
本记录不将标签推送或 workflow 启动视为发布完成；最终发布状态以 npm 注册表及完整工作流结果为准。
