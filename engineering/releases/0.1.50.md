# Wake 0.1.50

本补丁修复原生开发代理在 5 秒后截断正常慢请求的问题，继续使用原生代理。

- HTTP 请求默认不设响应头等待总上限；`request_timeout_ms` 可设有限值，省略或 0 禁用。
- `connect_timeout_ms` 独立限制 TCP/DNS 连接，默认 5000 毫秒；响应流不受请求上限影响。
- 转发失败不重试，提示上游执行结果可能未知，避免写请求重复执行。
- 客户端取消释放等待响应头和空闲 SSE 的上游连接。开发服务收到 HTTP/1 FIN 即终止请求，不支持 TCP 半关闭。
- WebSocket 升级策略保持不变。

本地 Windows / Node 22.15.0 / Yarn PnP 已通过原生绑定集成与 6.2 秒复现；
直连和原生代理均返回 200。覆盖默认、禁用及有限超时、慢 JSON、延迟 SSE、取消、
上游不可达、不重放与 WebSocket。受影响 config、dev_server、app crate 默认测试、
all-targets Clippy、格式及文档检查通过；默认 ignored 测试未运行。

标签工作流执行完整 workspace 门禁、五平台构建、八个不可变 tarball 审计、
发布前后干净安装验证。消费者应在发布后升级并移除临时代理，再验证真实接口。
