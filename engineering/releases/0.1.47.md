# Wake 0.1.47

状态：候选已在 npm 发布前取消，未发布。CI 拒绝升级后的系统浏览器镜像，后续版本见 [0.1.48](0.1.48.md)。原标签保留为审计记录。

本次发布统一开发与生产的 HTML 模板，并补齐应用资源、Worker、开发代理和库输出能力。

- HTML 只选择一个文件：显式 `html.template`，否则项目根 `index.html`；默认文件不存在时使用内置外壳。开发和生产都不再搜索 `public/index.html`。原模板位于该处的项目需显式配置路径或移动文件。
- `public/` 普通文件与应用输出一起原子发布，包含资源清单与过期文件清理；碰撞、链接或复制失败保留上一次成功输出。
- 开发代理逐块转发 SSE；`ws = true` 支持 WebSocket 数据帧、控制帧、子协议和关闭原因，单帧上限为 16 MiB，服务关闭释放连接及端口。
- 支持静态 `new URL('./asset', import.meta.url)` 和 `new Worker(new URL('./worker.js', import.meta.url))`。Worker 独立、顺序构建；资源参与缓存和发布，开发监听覆盖 `scripts/`、二进制及缺失文件恢复。静态引用限定项目根内，并检查 canonical 文件身份。
- `build()`、`createBuildContext()`、`bundle()`、`startDevServer()` 接受表达式字符串形式的 `define`，覆盖同名 TOML 定义并在开发重载时保持生效；`import.meta.hot` 保留给 Wake。
- `bundle()` 与两套 CLI 支持受限同步 ESM 及 `banner` / `footer`，source map 同步偏移。ESM 首版要求无 external，入口为直接、不可变导出；可变导出、再导出、CommonJS 全局、require、eval、import.meta 和顶层 await 显式报错。

本版本同时包含 `v0.1.46` 之后已合入的原生 lint 显式扩展授权、Docs Demo 视觉测试、Wake Test 的 Git 基线选择与工程控制、原始源码覆盖率，以及 UTF-16 模块来源、CDP 写背压和组件依赖修复。相关测试能力继续遵循文档中的 experimental 边界。

本轮功能在 Windows 上通过 1,143 项相关 Rust 测试、60 项架构测试和 10 项原生 Node 集成测试，以及类型、格式和 Clippy 检查。六个实际 Monaco Worker 连续两轮构建成功，未观察到持续增长；当前调试构建单次峰值仍约 952 MiB，未承诺消除大型 Worker 的峰值内存。

本候选原计划同步发布八个 npm 包，但标签工作流在发布前取消；上述能力随 0.1.48 继续验证和发布。本次不发布 VS Code 扩展。
